# FMMS - Files Metadata Management System

FMMS (Files Metadata Management System) — это приложение настольного типа, предназначенное для глубокого анализа файлов и метаданных, включая файлы, находящиеся внутри архивов. Приложение предоставляет мощные инструменты для анализа файловой системы, управления метаданными и генерации отчетов.

![Main Window](https://github.com/user-attachments/assets/9d366b44-d85e-4bf4-a0da-3cead40b2bcb)

## 🚀 Функции

### 🔍 Анализ файлов
- **Выбор источника**: Укажите путь к папке или перетащите архив прямо в окно программы
- **Нумерация файлов**: Включите/отключите нумерацию файлов в таблице (влияет на формат копирования)
- **Анализ архивов**: Опционально анализируйте файлы внутри архивов (ZIP, RAR и другие)
- **Обработка**: Запустите процесс анализа файлов
- **Экспорт результатов**: Сохраните результаты в формате `.txt` или `.xlsx`

![File Analysis](https://github.com/user-attachments/assets/c6726f10-b901-421d-aced-9d51c55fb619)

#### Контекстное меню
- **Открыть файл** — открыть выбранный файл стандартной программой
- **Открыть папку файла** — открыть папку, содержащую файл, с выделением
- **Копировать** — скопировать информацию о файле в формате:
  ```
  Путь до проанализированной папки: C:\Users\Glaz_almaz\Desktop\Всё\Pictures
  Индекс: 2; Путь к файлу: \Аватарки; Кол-во стр: 1; Расш: .gif; SHA256: d3a78d8d7db687b625f26cf68d3bacce518e37e9172fd596b91d7ecdaa53b351
  ```
- **Копировать как TSV** — скопировать информацию в формате, подходящем для импорта в Excel
  ```
  FileName	FolderRelativePath	PagesCount	FileExtension	FileSHA256
  Profile Icon.jpg	\Аватарки	1	.jpg	080f449eab077251fc7aeff3e140dc8b42e13e3fc1670e7a4c13b6ff017341a7
  ```
  ![TSV Example](https://github.com/user-attachments/assets/0c215540-8c00-4d3b-b01a-a833919cb69f)
- **Свойства файла** — открыть стандартное окно свойств файла
- **Настройка столбцов** — выбор отображаемых столбцов (настройки сохраняются в конфигурационный файл)

  ![Column Settings](https://github.com/user-attachments/assets/8d2bbfce-11c7-45b3-91f4-ef72f6249324)

#### Таблица файлов
Таблица отображает следующие данные:
- **#** — порядковый номер файла (если включена нумерация)
- **Имя файла** — имя файла (например, `desktop.ini`)
- **Путь к файлу** — относительный путь до файла без имени файла
- **Стр.** — количество страниц в PDF-файле (иначе 0)
- **Расш.** — расширение файла (например, `.exe`)
- **SHA256** — хеш-сумма файла в формате SHA256
- **Полный путь** — полный путь до файла
- **Относительный путь** — путь до файла с именем, относительно корневой папки анализа
- **Архив** — указывает, является ли файл архивом
- **Запись в архиве** — указывает, находится ли файл внутри архива
- **Путь к архиву** — путь до родительского архива (если файл — запись внутри архива)
- **Сжатый размер (MB)** — сжатый размер файла в архиве
- **Не сжатый размер (MB)** — несжатый размер файла в архиве
- **Размер файла (MB)** — размер файла в мегабайтах
- **Размер файла (Byte)** — размер файла в байтах

### 💾 Анализ дисков
- **Обновление списка** — получение информации о дисках и папках: имя, тип (папка / файл), размер (МБ) и количество файлов
- **Раскрытие папок** — отображение содержимого папки одним кликом
